# Copilot Playground

A simple React + TypeScript app powered by Vite, with an interactive counter and
small feature ideas for experimenting with GitHub Copilot. No backend or API keys
are required. Counter state resets when the page reloads.

## Run locally

Use Node.js 22.12+ (or 20.19+) and npm.

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite. Edit `src\App.tsx` to start experimenting.

## Commands

```powershell
npm run build    # Type-check and build into dist
npm run lint     # Run Oxlint
npm run preview  # Serve the production build after running build
```
